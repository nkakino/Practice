git init　：リポジトリを作成
git remote add origin <リポジトリ名>　:リモートリポジトリを連携

▼Git管理（既存PJを利用する場合）
git clone <リポジトリ名>　:リモートリポジトリからコピーする　

<リポジトリ名>
（Githubで作成したリンクをペースト）
---例---
git clone https://github.com/nkakino/Practice.git

▼開発の流れ
リポジトリは変更履歴を記録する場所

ステージングエリアはファイルを変更したときにコミットするファイルを選択するためにある
git addでステージングエリアに追加する

コミットは変更にメッセージをつけてリポジトリに記録する
git commitすると変更がリポジトリ内に時系列で記録される

コミットメッセージ　※なにをどうして変更したのか、ほかのメンバーに分かるように記載
1行目：変更内容の要約
2行目：空行
3行目：変更した理由

git add .　：変更をステージングエリアへ追加
git commit　：変更をローカルリポジトリにコミット
git commit -m ＜メッセージ＞　：
git commit -v　：変更内容を確認

git mv <旧ファイル> <新ファイル>　：ファイル名の変更を記録（ステージングエリアに反映される）
★以下の３つのコマンドと同じ
mv <旧ファイル> <新ファイル>　：ローカルのファイル名が変更される
git rm <旧ファイル>　：<旧ファイル>を削除
git add <新ファイル>　：<新ファイル>をステージに追加

git log　：リポジトリにコミットされた履歴を表示
git log --oneline　：1行で表示する
git log -n 3　：最新のナンバー（３つ）分表示する
git log --oneline -n 3　：最新のナンバー（３つ）分１行で表示する
git log -p　：変更履歴の差分を表示する
git log -p <ファイル名>　：変更履歴の差分を指定したファイル名の分のみ表示する

git diff　：ファイルの変更差分を確認（differenceの略）　※ステージングエリアとの差分
git diff HEAD　：ファイルの変更差分を確認　※ステージングエリアとコミットの差分

git merge <取り込みたいブランチ名>　：取り込み先は今いるブランチ　※先にgit branchで確認する
git stash　：変更中のファイルを一時保管する
touch　：空ファイルの作成

▼その他

rm　：ファイルを削除
cp　：ファイルをコピー
